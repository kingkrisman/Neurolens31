# Fonts

Latin subsets, regular (400) and bold (700), of the typefaces the NeuroLens
reader offers. Every one is published under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with software.

| File | Typeface | Designer |
| --- | --- | --- |
| `serif-*` | Newsreader | Production Type |
| `lexend-*` | Lexend | Bonnie Shaver-Troup, Thomas Jockin and contributors |
| `atkinson-*` | Atkinson Hyperlegible | Braille Institute of America, Applied Design Works |
| `inclusive-*` | Inclusive Sans | Olivia King |
| `andika-*` | Andika | SIL International |
| `opendyslexic-*` | OpenDyslexic | Abbie Gonzalez |
| `literata-*` | Literata | TypeTogether |
| `comicneue-*` | Comic Neue | Craig Rozynski and Hrant Papazian |
| `sourcesans-*` | Source Sans 3 | Paul D. Hunt, Adobe |

The files are unmodified apart from subsetting, which Google Fonts does when it
serves them. The extension registers each one under an "NL " family name so it
never collides with a font a website defines.
